# Vue 2 — планировщик задач

Учебный проект на Vue.js 2, созданный для практики разработки компонентных интерфейсов и работы с реактивными данными.

Приложение представляет собой простой планировщик задач в формате Kanban-доски: задачи можно создавать, отмечать выполненные пункты, перемещать между этапами и сохранять в браузере.

## Возможности

- создание карточек с заголовком и списком задач;
- добавление от 3 до 5 пунктов в карточку;
- удаление дополнительных пунктов;
- поиск карточек по заголовку;
- автоматическое перемещение карточек между колонками:
  - **Списки** — новые задачи;
  - **В процессе** — задачи, выполненные минимум наполовину;
  - **Готово** — полностью выполненные задачи;
- отображение даты завершения карточки;
- очистка списка завершённых задач;
- сохранение данных в `localStorage`;
- блокировка отдельных действий при достижении лимита задач в работе.

## Компоненты Vue

В проекте используются следующие компоненты:

- `app` — корневой компонент и управление состоянием приложения;
- `create-card` — форма создания новой карточки;
- `board-column` — колонка Kanban-доски;
- `note-card` — отдельная карточка с задачами.

## Запуск проекта

Проект не требует сборки и установки зависимостей. Vue.js и Bootstrap подключаются непосредственно из файлов проекта и CDN.

### Быстрый запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Qu1styy/Vue2.git
```

2. Перейдите в папку проекта:

```bash
cd Vue2
```

3. Откройте файл `index.html` в браузере.

### Запуск через локальный сервер

Для запуска через простой локальный сервер Python выполните:

```bash
python -m http.server 8000
```

Затем откройте страницу:

```text
http://localhost:8000
```

## Как пользоваться

1. Введите заголовок новой карточки.
2. Заполните минимум три пункта.
3. Нажмите кнопку **Создать**.
4. Отмечайте пункты выполненными — карточка будет автоматически перемещаться по колонкам.
5. Используйте поле поиска для фильтрации карточек.
6. В колонке **Готово** можно удалить все завершённые задачи.

## Учебные цели

Проект создан для закрепления следующих тем Vue.js:

- создание и регистрация компонентов;
- передача данных через `props`;
- взаимодействие компонентов через `$emit`;
- работа с `data`, `computed` и `methods`;
- обработка событий и двустороннее связывание через `v-model`;
- использование директив `v-if`, `v-for`, `v-bind` и `v-on`;
- сохранение состояния приложения в `localStorage`;
- работа с формами и валидацией пользовательского ввода.

## Ограничения проекта

Это учебное приложение, поэтому данные сохраняются только в браузере пользователя и не синхронизируются с сервером. Авторизация, база данных и сетевое API не используются.
